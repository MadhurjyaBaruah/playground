# Playground

A collection of experiments, prototypes, and technology explorations.

---

## About

This repository is my personal playground where I try new technologies, frameworks, libraries, tools, and ideas.

Not every experiment becomes a complete project. Some are simple tests, while others may grow into larger applications in the future.

---

## Purpose

The goal of this repository is to:

* Explore new technologies
* Learn by experimenting
* Test ideas before starting a project
* Build small prototypes
* Keep track of interesting discoveries
